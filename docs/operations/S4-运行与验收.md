# S4 运行与验收

GlobalSite feat/s4-agents；GlobalCRM 未修改。基于已合并 S3，站点/页面/事实与任务仍在独立 globalsite 数据库。

## 运行

```sh
npm run typecheck
npm run build
npm run lint
npm test
docker compose up -d --build --wait
npm run test:e2e
```

打开 http://localhost:5080/sites。AI 可选：组织管理员在 AI 服务商页配置；未配置时任务 paused，手工规划/页面编辑/审核仍可用。前端同意发送组织资料后才允许触发 AI，未执行真实付费调用。

本地测试使用缓存 MongoDB 8.2.6 的临时副本集，CI 默认 MongoDB 7.0.14、Node 20.19。Compose Node 22；镜像沿用 npm ci --ignore-scripts。

## 测试覆盖

- Site/SitePage/SiteBlock tenant fail-closed、跨组织查询/外键、只读角色、站点套餐限制、Logo 引用保护。
- 地图非法路径/循环层级/产品范围、管理员确认、路径交换后旧批准失效且可继续保存。
- 未确认或无来源数字/全角数字/英文年份/认证/产能阻断批准与发布检查；无关引用无法证明认证；确认事实撤回后立即阻断。
- 产品区块/规格表、FAQ 直接回答字数、页面修改撤回批准、固定 HTML 渲染转义脚本。
- 并发同一步骤返回同一个运行和任务；完成重放无重复写入；多页失败只补失败页。
- 已落库输出恢复不重复模型请求；旧租约及旧派发代次不能提交；单段重写不修改其他段落；人工编辑不会被旧运行覆盖。
- 真实额度预留路径超额时，在发送 HTTP 前拒绝并暂停；恢复保留输入/已完成页；未知调用保持预留且不自动重复。
- 取消执行中的请求不写页面；撤销发起人编辑权限阻止继续执行；访谈回答幂等写候选事实，规划结果需人确认。
- 真实 HTTP 的成功请求/响应和错误响应经本站 OpenAPI 校验；模拟服务保留配置模型并结算实际 tokens。
- 前端中英文字典及同源深链接；站点地图移动保持树形层级并拒绝循环。
- 浏览器沿用 S2/S3 全部流程，加 S4 建站、地图编辑/确认、缺来源红色问题/禁止批准、预览、批准后编辑撤回、AI 未配置暂停和取消、中英文、390px 地图按钮替代拖拽。

## 浏览器环境

本机真实服务和原有 globalsite_mongo/globalsite_storage 保留。反复验收放在独立 Compose 项目 globalsite-s4-e2e、5180 端口、独立临时数据卷，不修改原有限流。测试在认证聚合频率限制返回 429 时，遵守 Retry-After 后重试一次；桌面与手机共用同一个合成测试账号。

CI 使用新建环境运行完整五条浏览器流程，浏览器作业仍固定 Ubuntu 24.04。测试截图只包含合成账号和合成企业，未提交到仓库。

## 限制

关键词研究是模型建议；没有实时搜索量数据。真实模型响应质量、第三方模型兼容性及实际账单需组织配置后验证；本站没有代为调用真实服务。事实校验为保守规则和人工审核结合，不能代替业务人员确认材料。完整构建/上线仍为后续任务，不把审核就绪误称为已发布。

没有新环境变量/依赖。自动迁移新增模型/索引和 S4 账本，不移动旧数据。生产依赖既有 moderate 告警保留，high/critical 门槛不降低。
