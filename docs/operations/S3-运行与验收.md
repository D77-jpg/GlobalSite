# S3 运行与验收

仓库 GlobalSite，分支 feat/s3-products-facts；GlobalCRM 仅只读核对 C1 契约及安全读取器来源。基于已合并 S2 主线 ca03e75c23a8662e28cc5bbdaf37df6df6c1a99b。

## 验收入口

```sh
npm ci --ignore-scripts
npm run typecheck
npm run build
npm run lint
npm test
npm audit --audit-level=high
docker compose up -d --build --wait
npm run test:e2e
```

本地测试使用隔离临时 MongoDB 副本集（本机缓存 8.2.6）；CI 固定 Node 20.19 + MongoDB 7.0.14。本机 Node 24，Compose Node 22。未向源码提交本机数据库程序或路径。

网页入口 http://localhost:5080；原有 globalsite_mongo/globalsite_storage 卷保留。注册及验证流程沿用 S2；新增导航为产品库、资料库、企业事实库、旧官网读取。

## 测试覆盖

- 产品组织隔离、只读角色、非法字段、乐观版本、跨组织图片/事实外键。
- Excel 可配置映射、真实物理行号、错误行/重复编号/已有编号、公式及危险压缩包；确认幂等、恢复不重复产品、失效租约拒绝写入、发起人撤权后拒绝任务。
- 新图片真实解码、WebP 与缩略尺寸、无 EXIF、私有下载、PDF 附件、引用保护、衍生图累计存储额度及删除后扣减一次。
- 事实确认/驳回/编辑重新审核，完整版本历史，来源修改撤回确认，跨组织来源不可见。
- 模拟 AI 使用配置模型、丢弃无逐字依据的文字结果、已知用量结算、未知用量保留预留、已保存结果恢复不重复调用、来源版本失效、超额在出站前拒绝。
- 真实 PDF 解析文字、空白/扫描 PDF 不发送模型请求；图片输出保持未核实候选。
- 拒绝内网/本机/IP/危险端口，混合 DNS 结果拒绝、连接固定 IP、跳转后 DNS 再次变为内网时不建立第二条连接；robots 与站外链接限制。
- 模拟旧站读取生成结构/产品草稿/候选事实/迁移 CSV；CRM C1 消费映射的稳定 ID、空值、图片时效地址分离。
- 所有 JSON 成功请求与响应经本站 OpenAPI 校验；错误响应同样校验。原有 S2 账号/会话/安全/租户/计量测试继续保留。S2 旧伪 PNG 测试样本换成有效 PNG，拒绝非图片的断言保留。
- 浏览器实际 Compose：桌面图片上传、规格键值和表格、产品保存后重载、导入 Worker 完成、事实审核和历史、内网网址拒绝、中英文切换；390px 移动端所有新页面与事实录入，原有注册/验证/登录/成员/两步验证流程。截图只用合成账号。

## 外部服务与限制

没有真实 AI 密钥或付费调用；测试以模拟 HTTP/提取器验证请求、计量和候选行为。真实 OpenAI 需组织管理员配置适合 JSON/图片能力的模型；用户须明确勾选发送资料的同意。没有对任意真实旧站发起读取，网络安全与提取使用受控模拟响应。

生产依赖审计仍有既有 Router 6 的两项 moderate 包告警；high/critical 门槛阻断策略保留。具体告警及适用边界见 S3 设计文档，未执行 audit fix --force 或升级指定技术栈。

本地文件存储、无扫描 PDF OCR、非全站穷举、故障对账与旧文件不自动衍生等边界见 [S3 设计](../design/S3-产品与事实.md)。CRM 未运行测试，因为本任务未修改该仓库。
