## 改动摘要

- S8：采购定位、最多三个参考站的安全结构读取、确认事实缺口、可编辑逐页目的/采购问题/区块计划、优先补齐采购资料的访谈。
- S9：十五种白名单区块、差异化首页/目录/产品布局、图片与显式 PDF 资源、密度与按钮目标设置、完整私有编辑预览。
- S10：真实 Worker 截图、文字/视觉能力明确区分、无 AI 的浏览器检查降级、当前修订校验、人工质量确认、按报告生成新草稿、修订进度。
- S11：跨页面产品询价清单、分类/搜索、静态目录下载、采购事实与质量发布门禁。Cookie 面板与询价清单分层，不遮挡清单操作。

## 契约与数据

唯一本站 API 以 foundation.openapi.yaml 为准：新增 GET /sites/{id}/buyer-readiness、GET /agent-runs/{id}/screenshots/{key}/{width}、POST /agent-runs/{id}/accept-review；Agent 增加 review/refine；扩展可选 buyerProfile、page brief、block items/layout/tone、presentation density/action target、provider supportsVision。CRM scopes/Integration API 无变化。

没有新集合、索引或强制迁移。旧页面可省略可选字段，旧 SiteVersion zip 保持原字节。截图使用现有私有存储和用量结算；稳定收据避免恢复时重复构建/计量。只在本机按用户授权将开发组织调整到现有 Growth 测试套餐，原消耗/预留记录保留；不涉及付款或生产账号。

## 真实 Agent 与实际产物

使用组织已配置的本地 cn:deepseek-v4.1-flash，经应用界面触发真实 Worker。没有把手写页面计作 Agent 输出，没有复制密钥或修改用量记录。

- 规划输出六页，包含采购目的、问题和区块计划；缺商业证据时移除无依据的工厂/认证介绍页。
- 六页内容生成完成，首次全站 review 完成；真实 18 张截图覆盖 375/768/1440，横向溢出 0、加载失败图片 0。

## 限制与人工事项

PurrNest 当前为概念演示，尚无已确认企业/产品事实。商业发布仍须确认公司名称、业务联系邮箱和产品材质、规格、MOQ、交期等资料；页面通过构建检查不会补齐这些数据。图片为既有概念素材，不能当作实拍证明。

当前模型未开启图片输入，AI 报告基于文字和浏览器测量；截图需人工看图。模型已知格式失败使用原有有界重试并照常计量，未知用量保持暂停。事实校验为规则与人工审核组合，不能宣称能证明任意营销声明。

目录提供静态 HTML 与显式选择的已上传 PDF，尚无自动专业 PDF 排版。Cloudflare 未配置，保留登录预览和 zip；公网发布、真实邮件/表单接收及完整 CRM 联调需在其部署配置中验证。无需手动运行数据库迁移。
