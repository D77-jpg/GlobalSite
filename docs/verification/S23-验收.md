## 2. 改动摘要

- 可确认的业务策略与集中追问，按购买路径选择导航和资料要求。

## 8. 限制与人工操作

- 当前模型 `cn:deepseek-v4.1-flash` 配置为不支持图像输入。真实运行是文字/结构检查 + 浏览器测量 + 人工看图，不声称模型看过截图。支持图像的服务商可在组织 AI 设置显式启用后使用图像审查分支。
- 三业务验证为隔离合成回归；真实模型完整试点仅 VELATURO。不能把合成 Lighthouse 成绩当真实业务站的成绩。
- 真实模型曾多次返回格式/内容不合格结果，因此拆为四页单元并保留付费成果。仍存在等待和模型输出质量限制，不承诺一次生成必达顶级设计。
- 本轮不公开发布，不扩展未选定方向。用户在产品中选择方向，再确认两页与截图审查后扩展整站；真实规格、价格/交期等缺口须企业确认。
- 无需手工迁移数据库或重新录入已有资料。后续生产发布使用正常完整 Docker 构建和依赖锁；本机调试为编译产物增量镜像，CI 会执行干净安装及完整镜像构建。

最终三业务合成成绩：business-art 性能 98 / SEO 100；business-engineering 性能 98 / SEO 100；business-bags 性能 98 / SEO 100。
