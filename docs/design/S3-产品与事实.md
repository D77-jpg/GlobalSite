# S3 产品、资料与事实库

本阶段只修改 GlobalSite，分支 feat/s3-products-facts。GlobalCRM 只读；不连接 CRM 数据库，不调用尚未实现的草案接口。

## 使用流程

1. 资料库上传 PNG/JPEG/WebP/PDF 或证书。
2. 产品库手工录入产品，维护键值规格、表格规格与图片；也可上传 Excel，调整字段映射，查看错误行，再确认导入有效行。
3. 手工添加事实，或明确同意后从产品/资料中提取候选事实。未配置 AI 时可继续手工操作。
4. 组织管理员打开来源核实，再逐条确认或驳回。编辑员可维护资料和候选事实；只读成员只能浏览。
5. 可选读取旧官网。只抓公开页面，生成页面结构、产品草稿、企业候选事实与旧 URL 清单，结果不会自动成为已确认事实。

后续建站必须以 status=confirmed 的事实为硬数据来源。产品、网页及 AI 候选的存在不代表其已通过审核。

## 数据模型与索引

所有业务模型通过同一个 entity/tenant 插件注册，查询从会话或任务组织上下文取 organizationId。客户端不能指定跨组织范围；外键也校验本组织数据。新增集合沿用 Mongoose 默认命名，不修改已有集合名称。

事实 source 包含 kind（manual/product/asset/website/globalcrm）、refId/url、quote、可选 label、revision/sha256、capturedAt、textVerified。S3 允许本地及已完成旧站任务作为来源；globalcrm 为后续同步保留，不能由浏览器伪造远端来源。

source.kind=product 的已确认事实，在产品修改时同一事务撤回到 candidate，版本递增并记录 before/after。确认时检查产品版本或文件哈希；对产品/文件记录加引用锁，避免与修改/删除发生竞态。网站来源引用不可变的读取快照；再次读取相同值会去重，变化产生新候选，不自动改写用户内容或替代旧的审核判断。

## 迁移与兼容

启动迁移仍初始化所有模型索引，新增幂等账本 s3-products-facts-v1。无需手工数据搬迁；已有用户、组织、会话、文件、数据卷保留，库名仍为 globalsite。

旧 Asset 缺少新字段时以 fileName=asset、kind=image、totalBytes=bytes 返回，旧文件可下载；旧文件不会在启动时重写，也不会自动生成衍生图。新上传的图片会解码、移除 EXIF、应用方向并缩放至最长边 2400，再保存规范化原图；下载原件指该安全处理后的文件。缩略图最长边 320，另有 1600 WebP；禁止多帧、超过 2000 万像素或损坏的图片。

POST /assets 仍保留 S2 的 {id,bytes,mime} 响应结构，GET /assets 返回扩展资料信息，图片衍生通过 ?variant=thumb|webp 读取。所有文件必须有 Cookie 会话，不提供公共或永久地址，响应 private,no-store；PDF 强制附件下载。

新上传文件、衍生文件一并预留并计入 lifetime storage_bytes。删除成功后仅扣减一次。存储仍为本地持久卷，未新增 MinIO、环境变量或无配置即启动失败的服务。进程/磁盘故障后的孤立文件和未结算额度仍需运维对账；没有擅自删除或释放未知状态的数据。

## Excel 导入

支持 .xlsx 和 UTF-8 .csv，最多 5 MiB、500 条物理数据行、40 列；只读取第一个工作表。空行忽略，报告保留原始行号；表头非空且唯一。XLSX 解压前限制条目数和总大小，拒绝宏、外部链接和嵌入对象，再重打包后交给 SheetJS；公式/错误单元格不可作为产品字段。

字段映射为“产品字段 → 文件列名”，可识别部分中英文表头，上传不写产品。规格参数支持 JSON 对象或完整规格数组；规格表：

```json
{ "columns": ["Model", "Weight"], "rows": [["A", "10 kg"]] }
```

认证可用分号、逗号或竖线分隔。空 SKU 自动生成；文件重复 SKU、已有 SKU、缺少名称和非法字段逐行报告，现有产品不会被覆盖。确认接受全部有效行，也支持 API 指定行；选中的坏行会被拒绝。错误报告 CSV 进行公式注入防护。

状态 preview→queued→running→complete/failed。确认按原 revision+行选择幂等，同一导入只有一个任务；每行产品、结果与审计在同一事务落库，重启按结果继续。租约 owner+fencingToken+有效期保护每次写入，过期持有者不能提交；只对瞬时导入故障退避重试，最多 8 次。

## AI 候选提取与计量

产品使用结构化文字，PDF 只解析可提取文字（最多 50 页，最多取 24000 字符）；扫描 PDF 不自动 OCR，可手工录入或上传图片。图片规范化缩小后通过 image_url 发送，读取结果 textVerified=false，界面明确提示需要对照原图。

仅在成员勾选同意后排队；Worker 在执行和提交时重新校验组织与发起人当前编辑权限。未配置 AI 则任务明确失败，手工产品/事实功能仍可用。使用 S2 组织级加密提供商设置，固定官方 OpenAI 地址，完全保留管理员配置的模型，不替换模型或自动调用默认模型。

输入作为不可信数据，禁止执行内容指令；模型只能返回受限 JSON 候选。文字候选的 quote 必须逐字出现在来源，value 必须出现在 quote；不符合的项丢弃。图片不宣称文字已核实。全部结果均为 candidate。

调用前预留保守的输入/输出额度；已知 usage.total_tokens 按实际计量。结果先保存到 AgentRun.pendingResult，再幂等结算和写事实；恢复时复用结果。网络超时/用量未知保留预留，禁止自动重复付费调用。可用组织额度不足时在发送请求前拒绝。本阶段测试为模拟服务，没有使用真实密钥或产生模型费用。

实现依据：[OpenAI Chat Completions 官方参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。供应商参数兼容由配置模型决定；不支持 JSON 输出或图片的模型会明确失败，需管理员选择适用配置。

## 旧官网安全读取

网站读取器从 GlobalCRM server/src/services/website/public-web.ts @60cdbc48035301c152a58b924558b08a850fa36a 复制后独立改造；保留来源注释，没有运行时依赖。S2 的提供商 URL 校验独立保留。

只允许 HTTP(S) 公开域名与标准端口，拒绝账号口令、IP 字面量、本机/内网后缀。每次请求和跳转重新解析所有 IPv4 结果；任一受限结果即拒绝，并将通过的 IP 固定到实际连接，HTTPS 仍验证原域名证书。不采用系统代理、Cookie 或 Authorization，不执行脚本，不获取附件或站外页面，不允许 HTTPS 降级；跳转限制 3 次。

User-Agent=GlobalSite-Reader/1.0。先读取 robots.txt（404 视为空规则，其余异常保守失败），支持本机器人组及通配规则，并在跳转前检查。每页 2 MiB、单次链路 12 秒、解析等待有界；仅接受 UTF-8/ASCII HTML，robots 最多 128 KiB，不接受压缩响应。HTML 403/429 有限退避两次，遇访问限制不会尝试绕过。

一次最多 1–8 页，限定同域（允许 www 形式）广度优先。去除 query/hash 合并 URL，迁移清单记录已读取与 robots 拒绝的 URL；不是全站穷举工具。提取 title/h1-h3/链接、Organization JSON-LD 公司资料、Product JSON-LD 或产品路径标题；隐藏脚本和样式不作为正文。没有结构化信息的复杂网站可能只获得页面结构与标题，需人工补充资料。产品只建 draft，重复读取不覆盖人工编辑。

## CRM 对照与 API

CRM 唯一契约：[integration-v1.openapi.yaml](https://github.com/D77-jpg/GlobalCRM/blob/60cdbc48035301c152a58b924558b08a850fa36a/docs/integration/integration-v1.openapi.yaml) 与 [globalsite-对接设计.md](https://github.com/D77-jpg/GlobalCRM/blob/60cdbc48035301c152a58b924558b08a850fa36a/docs/integration/globalsite-%E5%AF%B9%E6%8E%A5%E8%AE%BE%E8%AE%A1.md)。不在本站复制接口定义。

crm-product-mapping.ts 仅为该 C1 响应的消费映射：id→externalRef.remoteId，连接 ID→externalRef.connectionId，updatedAt→externalRef.remoteUpdatedAt，其余产品业务字段直接映射，保留 null/[]。图片时效 URL 只出现在 remoteImages 临时返回值中，不存作本站长期图片；S7 实现授权同步时须安全下载到本组织 Asset，再关联 assetIds。S3 不发送 CRM 请求、没有 CRM scope 变更。

本站新增接口的唯一可执行定义为 [foundation.openapi.yaml](../api/foundation.openapi.yaml)。列表为 ID 降序游标分页，默认为 30、最多 100。产品写入、事实修改、导入映射/确认均检查 revision；私有 API 一律要求当前会话，写入还要求 Origin+CSRF。新增：

- 产品 CRUD、导入列表/上传/映射/确认/错误 CSV；
- 资料列表、私有衍生图与下载（保留既有上传/删除）；
- 事实列表/创建/编辑/确认/驳回/修改历史；
- AI 提取入队与任务查询；
- 旧站读取入队/列表/详情/迁移 CSV。

## 范围与后续

没有修改 CRM 代码、环境或集合；没有新建 CRM 契约；无 CRM 同步 UI、站点生成/发布或询盘功能。旧官网读取、资料与 AI 候选均不能跳过人工审核。

文件不含自动病毒扫描或对象存储隔离，不能当作公开文件服务；上传仅组织成员可读，PDF 不内嵌执行。扫描 PDF OCR、大批量导入/旧站全站爬取、存储自动对账、保留期限清理在后续任务中实现。事实来源一经复核才可使用，后续 builder 仍需独立测试“未确认事实不能构建”的门禁。

既有 Router 6 审计有 2 项 moderate 生产包告警，按指定栈未升级到 7。链接采用静态内部路径和经过白名单校验的返回地址；使用 BrowserRouter 声明模式，无 SSR/hydration。仍需跟进 [导航告警](https://github.com/advisories/GHSA-wrjc-x8rr-h8h6) 与 [SSR 告警](https://github.com/advisories/GHSA-337j-9hxr-rhxg)，不宣称零漏洞。
