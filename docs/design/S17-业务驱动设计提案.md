# 业务驱动设计提案与整站生成

## 数据与契约

本站 foundation.openapi.yaml 增加 adaptive 创建模式、可选 businessBrief、Agent design 步骤、GET /sites/{id}/design-proposals/{runId}/{key}/preview 和 POST /sites/{id}/design-direction。CRM 无变化。Site 可选 designDirection 记录所选任务、方向、视觉体系、首屏布局、密度和私有设计理由。AgentRun 原有冻结输入和步骤输出保存两个方向及首页草稿。不增加集合或索引，旧站字段缺省继续运行。

## 用户流程

创建页只描述业务目标并选用现有产品，行业版式选择移除。已确认组织事实与选用产品进入现有研究和访谈流程；业务描述是私有建站指引。确认站点结构后，design Worker 一次生成 primary/alternate 两个完整首页方向。可在后台比较实际渲染结果、放大预览、用自然语言提出设计修改，并发起下一轮提案。每轮实际使用量按原AI规则计费，显式同意后才执行。

选定方向在事务内写入站点规则和首页待审核草稿，撤回旧内容批准。默认整站生成保留选定首页，补齐内页；显式单页重生成仍可执行。所有页面使用同一视觉体系及密度，区块组合根据页面用途安排。方案以已验证的区块、布局与视觉规则组合，不再以行业枚举限制业务；当前支持的视觉与区块仍受可执行白名单约束。

人工逐页审核、事实校验、桌面/移动浏览器审查及修订、私有构建预览、导出与发布沿用原流程。设计提案预览是当前可信模板渲染的私有草稿，最终构建仍需检查。缺少真实资料时提示补充，不能生成虚构证明。

## 并发、安全与重试

设计任务使用现有内容锁、任务租约和围栏、冻结输入、幂等键、额度预留及已知/未知用量规则。完成结果先落盘后结算，重放不再次调用模型。选用时检查当前角色、同组织站点/任务归属、站点与规划版本、产品和事实修订、首页原始修订、活动任务及发布锁。相同选用重试只返回已有结果。资料或首页变更后旧方案不能覆盖新内容，要求重新生成。选定操作、草稿和审核撤回同事务审计。方案预览带 noindex、禁脚本；公开内容继续只允许白名单字段，密钥不进入输出。

## 验证

真实HTTP契约测试覆盖 design Worker、调用一次与重放、私有预览、跨组织拒绝、只读拒绝、事务并发选用、选用重试、草稿未批准、选定规则落实到内容、重复方案拒绝与过期首页冲突。浏览器验证移除行业选择、业务描述保存、提案发起与暂停、方案比较/重试/放大/选用的界面行为。模型适配使用隔离模拟服务，最终视觉质量需持续按真实企业资料评估。
