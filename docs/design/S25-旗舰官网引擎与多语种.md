# S25 旗舰级官网设计引擎、高转化 B2B 组件库与多语种建站

本阶段只修改 GlobalSite，分支 `feat/s25-flagship-storefront-i18n`，不修改 GlobalCRM 或其契约。

## 1. 目标与升级范围

1. **多语种独立站引擎**：解除原先仅支持英文（`language: "en"`）的硬限制，原生支持 `en / es / fr / de / ja / ar / ru / zh` 共 8 种语言（阿拉伯语自动启用 `dir="rtl"`）。全站导航、区块导语、产品筛选、询价清单、表单、Cookie 选择、404 页面与离线目录统一本地化，并向 Agent 传递目标语种约束。
2. **旗舰级品牌视觉系统**：在不引入外部 CDN 依赖、不执行模型生成代码的前提下，将受控 `composition` 扩展至：
   - 配色：`graphite / cobalt / clay / forest / violet` + 旗舰配色 `obsidian / ivory / ocean / brand`（由站点 `--brand` 派生和谐表面与边框）；
   - 字体：`sans / editorial / technical` + `luxury / geometric`；
   - 可选表面节奏（`light / warm / contrast`）、页头风格（`classic / editorial / minimal`）与圆角几何（`sharp / subtle / rounded`）。
3. **四类高转化 B2B 旗舰组件**：
   - `gallery`：多图视觉画廊 + 渐进增强原生 `<dialog>` 键盘无障碍灯箱（无 JS 时仍完整可读）；
   - `metrics`：核心实证数据条（强绑定已确认事实 `refs`，无依据条目拒绝渲染并阻断审批）；
   - `certifications`：资质与合规认证墙（强绑定已确认事实 `refs`，支持证书缩略图与 PDF 下载）；
   - `showcase`：杂志级 Bento 专题与项目故事区块。
4. **管理员直连渠道与社媒配置 (`Site.brandChannels`)**：
   - 支持管理员配置 WhatsApp、电话、邮箱、微信、LinkedIn、YouTube（严格格式与域名校验，绝不由 AI 编造）；
   - 在独立站渲染不遮挡询价栏的悬浮联系入口（`.brand-dock`）与页脚社媒链接。

## 2. 安全、门禁与兼容性

- 事实防幻觉门禁保持严格：`metrics` 与 `certifications` 与 `evidence / case-study / customization` 同级校验，必须引用当前已确认事实且数值/认证受控；非英语站点放开 `CONTENT_NOT_ENGLISH` 与英文 FAQ 词数硬检查，同时继续执行所有硬数据、联系邮箱与链接校验；CJK 文本按字符密度计算内容深度。
- `<dialog>` 灯箱静态 HTML 不含空 `<img src="">`，由 `inquiry.js` 点击触发时动态插入，保证 `outputChecks` 与 `html-validate` 零告警。
- 全部新增字段为可选字段，历史站点、页面与不可变静态 zip 100% 兼容，无需数据库迁移。
