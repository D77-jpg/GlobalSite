# 一站式建站体验

原创建表单与站点列表混排，品牌色控件横跨整列，用户需要自行发现后续各标签的操作。创建入口改为独立的 /sites/new，引导填写业务目标后选择现有产品，创建成功直接进入建站向导。

## 创建流程

两步填写，第一步收集名称、市场、客户类型、建站目标和基础版式。目标写入现有 buyerProfile，作为私有建站指引；第二步搜索选用产品，跨分页保留选择，最多50项，可只看已选。允许先建站后补产品，创建过程不发起AI任务。使用现有 /sites 请求结构，保留后端幂等锁和审核规则。新站使用内部默认样式，移除用户侧品牌色和Logo取色操作，历史样式继续读取。

## 站点向导

默认显示资料、结构、内容、检查与预览四步。当前步骤取自真实产品和已确认事实、规划确认、规划对应页面及其审核状态。主操作按当前进度进入资料准备、启动研究、确认结构、启动内容、审核页面或构建发布。AI操作显式同意后使用现有Worker队列，页面保持向导，可离开后继续。暂停或失败优先展示任务处理入口及AI配置、用量入口。

完整规划、访谈、采购定位、质量报告和设置仍可直接访问。人工确认、事实校验、当前质量报告审批与商业发布检查沿用已有流程。构建与发布在原工作台操作，向导提供明确入口；不宣称已经自动上线。

## 验证

浏览器走创建两步、编辑和确认结构、事实阻断、页面审核、暂停恢复入口与语言切换；桌面和390像素手机检查新界面。原完整浏览器与单元测试继续运行。无数据迁移、依赖或CRM契约变更。
