## 数据模型与索引

所有模型接 tenant 插件。O=organizationId；业务引用先检查当前成员和同组织范围，不使用 populate 旁路访问全局身份资料。

| 模型            | 范围与字段                                                                                                                               | 关键索引                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| User            | 全局身份，仅 identity；规范邮箱、姓名、域分离 SHA256 后 bcrypt(12) 密码摘要、邮箱验证、authVersion、两步验证、失败次数、锁定截止、locale | unique emailNormalized                                 |
| Organization    | 全局组织根，仅 identity+受校验成员；name/slug/ownerUserId/plan/status                                                                    | unique slug                                            |
| Membership      | O、userId 或 invitedEmail、role/admin/editor/viewer、status、邀请码摘要/过期                                                             | unique O+userId partial；unique O+invitedEmail partial |
| Session         | O/userId、access/refresh/csrf 摘要、历史 refresh 摘要、authVersion、有效期、吊销、设备描述                                               | O+userId；expiresAt TTL                                |
| AuthToken       | O/userId、用途、随机 tokenHash、HMAC codeHash、authVersion、尝试次数、过期/单次消费                                                      | unique tokenHash；expiresAt TTL                        |
| AuditLog        | O/actorId/action/targetId/requestId/保留时间                                                                                             | O+createdAt；expiresAt TTL 180天                       |
| UsageRecord     | O/period/metric/operationId/amount/state/actual                                                                                          | unique O+metric+operationId                            |
| UsageBucket     | O/period/metric/consumed/reserved                                                                                                        | unique O+period+metric                                 |
| Asset           | O/key/bytes/mime/sha256/status                                                                                                           | unique O+key                                           |
| Task            | O/kind/encrypted payload/operationId/status/attempts/nextAttemptAt/leaseUntil/owner/fencingToken                                         | unique O+operationId；status+nextAttemptAt+leaseUntil  |
| AgentAiProvider | O/name/default、modelName/baseUrl/enabled、GCM secret                                                                                    | unique O+name                                          |
| RateLimit       | 系统 identity、IP/类别/分钟的摘要 key/count/expiresAt                                                                                    | unique key；expiresAt TTL                              |
| Migration       | 系统 identity、key/completedAt                                                                                                           | unique key                                             |

User/Organization 为认证所需全局根，不包含组织业务库内容。Session、Membership、AuthToken 的身份查询只允许带 \_id/userId/随机令牌摘要等约束；无上下文组织业务查询一律拒绝。聚合不允许跨集合 lookup/unionWith/out/merge 等阶段；insertMany/bulkWrite 与直接文档 update/delete 被阻止，使用有组织范围的 create/query 操作。测试清理使用 collection 仅限隔离测试数据库。

## 鉴权与一致性

- 注册以事务创建用户、组织、管理员；不发会话直到验证邮箱。
- 密码域分离预哈希避免 bcrypt 72 字节截断；兼容 12–128 字符及 Unicode。没有默认密码或管理员后门。
- access 15 分钟、refresh 14 天，HttpOnly，生产 Secure，SameSite=Lax；写操作校验 Origin 与双提交 CSRF，并核对数据库中的 CSRF 摘要。
- 登录密码五次错误锁定 15 分钟；OTP 五分钟、五次、单次消费。随机令牌只存摘要，低熵 OTP 使用服务端密钥 HMAC。
- 每次请求校验有效 Session、User.authVersion、组织状态和当前 Membership；密码重置/两步验证改变认证版本，阻止并发旧认证签发可用会话。两步验证变更保留当前会话，撤销其他会话。
- 席位分配通过组织根记录串行化事务，计入有效待接受邀请；所有者不能降级或移除；邀请绑定收件邮箱。
- 额度先原子预留再结算，重复 operationId 不重复计量或触发 AI；AI 网络结果不确定时保留预留额度，等待核对，不能无限免费重试。
- 文件按组织保存；图片最大 10 MiB，检查魔数/MIME；拒绝 SVG/HTML。S2 不处理文档解压、病毒扫描与 S3，后续需再加。
- 邮件至少一次投递，固定 Message-ID 辅助去重，不承诺收件端 exactly-once。发送失败最多八次；生产无 SMTP 保留待办而非启动失败。

## 迁移与部署

仅 globalsite 新库。api/worker 启动和 npm run migrate 都调用可重复的索引初始化与迁移账本；不使用 syncIndexes 删除未知索引。MongoDB 必须支持事务，因此 Compose 配置单节点副本集。上线前备份数据与独立主密钥；升级前运行迁移，回滚前检查新旧数据兼容性。初始 S2 不是现有 CRM 数据迁移。

Compose 为本地开发方案，loopback 5080/27018，无默认账号。生产需独立部署配置、Mongo 认证/网络限制、HTTPS、密钥管理、SMTP 与备份演练；不要把开发 Compose 当作生产安全基线。可选服务配置与所有新增运行变量在两份环境示例中记录。
