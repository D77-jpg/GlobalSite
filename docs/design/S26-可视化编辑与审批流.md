# S26 分屏所见即所得可视化编辑、局部 AI 改写与精简审批流

本阶段只修改 GlobalSite，分支 `feat/s26-visual-editor-workflow`，不修改 GlobalCRM 或其契约。

## 1. 核心升级

1. **实时无落盘草稿预览 (`POST /api/v1/pages/:id/preview-draft`)**：
   - 编辑器内任意改动标题、正文、区块排序、布局、配色/字体/表面/圆角设计轴时，450ms 防抖自动调用 `preview-draft` 在内存中即时渲染完整独立站 HTML 并返回实时事实门禁校验结果，**不落盘、不撤回既有页面审批**。
   - 右侧粘性实时画布支持桌面 / 平板（768px）/ 手机（390px）一键切换、手动刷新与收起/展开，仍复用受控打包样式（`trustedPreview`），不放宽父页面 CSP。
2. **可视化编辑增强**：
   - **撤销 / 重做（Undo / Redo）**：维护最多 30 步编辑历史栈，可随时回退与前进；
   - **区块拖拽排序 + 键盘上下移 + 一键复制区块**：支持 HTML5 拖放和无障碍按钮调整页面区块顺序；
   - **品牌设计轴即时微调**：在页面展示区直接切换 `palette / typography / surface / headerStyle / radius` 并实时看效果；
   - **区块内联局部 AI 改写**：选中区块内提供快捷指令标签（更精炼专业、强化采购价值、补充选型指导）及一键“保存并 AI 改写此区块”（未保存时先原子保存当前页再仅改写当前 `blockKey`，不影响其他区块）。
3. **非结构设置修改保留规划与设计方向**：
   - `saveSite` 区分结构性变更（名称、模板、目标市场、语言、产品列表、业务简述、采购定位）与展示/联系渠道变更（`brandChannels`、`brandColor`、`logoId`）；仅补充 WhatsApp/社媒、换 Logo 或微调品牌色不再清空 `confirmedPlanHash` 与 `designDirection`。
4. **管理员批量审核（零降级门禁）**：
   - `POST /api/v1/facts/batch-confirm`：在 `/facts` 勾选待确认候选事实批量确认，逐条执行原 `transitionFact` 修订锁与审计日志，冲突/跨组织条目安全跳过并报告。
   - `POST /api/v1/sites/:id/pages/batch-approve`：在站点页面列表一键批准全部合格页，逐页完整执行 `reviewPage` 与 `validatePage` 事实/组合门禁，不合规页面保持阻断并纳入 `skipped`。

## 2. 安全与兼容性

- 新增 3 个端点均先更新 `docs/api/foundation.openapi.yaml` 并具备真实 HTTP 契约、权限与跨组织隔离测试。
- 无数据库迁移或新环境变量；所有编辑保存仍遵守版本修订号与发布锁，审批门禁零松动。
