## 设计系统

- 背景以白与浅中性色为主；GlobalSite 标识保留品牌识别，绿色只用于确认/成功与少量品牌细节。主要操作为深色按钮，不把每个按钮染绿。
- 4px 基础尺度：8/12/16/24。主导航 208px，Agent 专注模式可收为图标导航；工作区以真实内容决定宽度。
- 正文 13–14px，说明不小于 12px；页面标题 22px，区块标题 14–16px。采用已有本地系统字体，无新增远程字体。
- 表格、文件画布、编辑文档、任务工作区、设置分区各用适合的结构。边界只分隔操作区域，不把所有内容包成卡片。
- 焦点可见、原生键盘操作、文字与图标共同表示状态；手机主操作 44px，窄屏用任务/成果/操作切换，不把三栏压缩为不可读小列。
- 加载/空/失败状态必须区分，保留已有内容的刷新失败提示；只有真实接口结果能作为成果，不能展示虚构健康分、进度或工作成果。
- 技术诊断不抢占主视线；说明围绕用户下一步，不用 Worker、Token 等实现术语代替任务结果。

## Agent 工作流

右侧执行面板提供明确的任务选择、补充要求与 AI 调用同意。调用既有 POST /sites/:id/agent-runs，沿用幂等键、租约锁与后端校验；不把自由输入假装成已实现的任意工具调用。已有任务可重试/取消；只读用户无执行操作。

左侧选择任务及历史，中间逐页查看产出、检查问题、依据与截图。问题分类来自记录中已有字段/固定映射，无依据时显示其他，不伪造分类或数量。任何改进仍产生待审核草稿，不能自动批准/发布。截图使用已有同组织权限路径，不暴露临时凭证。

## 实施与验收

顺序：基础界面和布局 → Agent 三栏真实执行与成果 → 各业务工作区 → 账号与设置 → 全量回归与截图检查。

运行 typecheck/build/lint/test 与完整浏览器回归；新增 Agent 执行、结果、筛选、错误恢复、只读与窄屏切换测试。截图使用隔离虚构账号，功能路径同时通过真实 HTTP/Worker 回归；不使用模拟成果代替真实业务验收。检查 1440/768/390/375，无页面溢出和丢失操作。接口、真实数据与租户/角色安全行为保持兼容。
