# S27 管理台前端架构重构、路由懒加载与设计系统收拢

本阶段只修改 GlobalSite 前端与测试，分支 `feat/s27-frontend-architecture-polish`，不修改后端 API、模型、迁移或 GlobalCRM。

## 1. 核心改进

1. **路由级代码分割与依赖分包（消除 Vite >500 kB 单体告警）**：
   - `web/src/main.tsx` 将工作台各业务模块（`overview`、`agent-workbench`、`crm`、`inquiries`、`publishing`、`site-journey`、`sites`、`catalog`）全部改为 `React.lazy()` + `<Suspense>` 按需加载；
   - `web/vite.config.ts` 配置 `manualChunks`，拆分 `vendor-react`、`vendor-icons`、`vendor-forms`，显著降低首屏登录与首页 JS 负载，彻底消除 Vite 主包超 500 kB 警告。
2. **页面草稿未保存改动对比 (`web/src/page-diff.ts`)**：
   - 抽取可测试纯函数 `diffPageDraft(original, draft)`，识别页面元信息、展示/品牌设计轴以及区块新增/移除/重排/修改；
   - 在 `PageEditor` 顶部展示可折叠的「未保存改动 (N)」清单，提升审核与微调信心。
3. **采购资料缺口引导式就地补全 (`web/src/b2b.tsx`)**：
   - 在「采购定位 → 资料覆盖度」缺口列表中为每项缺失事实增加「立即补充」内联表单，自动预填 `subjectType / subjectId / type` 并提交至既有 `POST /api/v1/facts`（保持待确认候选态与管理员复核门禁），减少页面来回跳转。
4. **统一设计令牌与表面层 (`web/src/surface.css`)**：
   - 建立 `--gs-*` 规范圆角、表面与阴影令牌，统一收拢分屏预览、变更对比、批量审核栏与缺口速填表单的视觉与响应式表现，保持严格 `style-src 'self'` CSP（零内联样式）。
