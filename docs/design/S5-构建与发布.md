# S5 静态构建与发布

本次仅 GlobalSite，基于 S4 的事实/审核门槛；无 CRM 调用、契约或数据库变更。本站 API 见 ../api/foundation.openapi.yaml；CRM 对接仍只引用 CRM 两份契约。

## 架构与版本选择

API 只提交 Mongo 持久任务。独立 Worker 一次领取一个任务，使用现有 owner + fencingToken + leaseUntil 续租，运行前后检查当前成员权限。Astro 在独立 Node 子进程构建；API 不等待构建。

按 MVP 设计使用 Astro，固定受锁文件保护的 7.4.5 系列。试验的 Astro 5 与 Lighthouse 12 引入 high/critical 漏洞，已移除；最终 Astro 7.4.5 + Lighthouse 13.6.0 的审计无 high/critical。Astro 要求 Node >=22.23.4，因此根/server/web engines、CI 和 Docker 基础镜像统一该最低版本；React 18 与其他既有业务依赖不升级。Node 22.23.4 满足任务 Node >=20.19 的范围。

构建只编译仓库内固定 Astro 路由，不编译用户/模型提供的代码；页面文字转义、JSON-LD 转义小于号、品牌色白名单。子进程不继承数据库、SMTP、Cloudflare、AI 密钥，仅接收环境白名单与冻结的页面输入；Node sockets/DNS/fetch 禁用，堆上限 512 MiB、90 秒超时。Astro 与 Vite 缓存均在任务目录，依赖目录只链接读取；结束清理本任务临时目录。子进程不是恶意任意代码的 OS 沙箱，不允许引入用户插件、脚本或自定义构建命令；多机器扩展时应给 builder 独立容器与只读依赖卷。

官方依据：[Astro programmatic build](https://docs.astro.build/en/reference/programmatic-reference/)。此 API 为实验性，版本锁定并用真实构建/容器回归保护，升级需重跑验收。

## 三个模板

machinery 为工业网格、左侧品牌强调与直角信息层级；building-hardware 为暖色材料背景、线性边框与工程卡片；packaging-bags 为居中 Hero、圆角产品卡和轻量包装视觉。行业数据库没有准确命中，使用技能默认的可访问性、移动优先和性能规则，并继承 GlobalSite 的组件习惯，没有持久化不匹配的行业推荐。

固定外壳包含 Hero、已审核产品页网格、询盘展示与页脚；优势、工厂照片、认证、案例、FAQ 和规格表由已审核 SiteBlock 提供，没有资料的内容不伪造。first image 用于 Hero，其余图片保留独立区块；key 为 advantages/factory/certifications/cases 的区块有相应视觉样式。模板无运行时 JS，details/summary FAQ 原生展开；内容在初始 HTML 中。

Logo 从本组织已清洗图片提取最多五个 RGB 候选色，透明像素忽略；无可用像素时返回默认色。提取不改站点。用户选择后复用 S4 更新接口，撤回地图确认和页面批准，并明确提示重新审核。品牌色用作装饰强调；正文/按钮采用固定深浅色，避免任意 Logo 色降低对比度。

图片复制为独立不可变 WebP，最长边 1600、质量 80，显式宽高与 decoding；Hero 优先，其余 lazy；每张图 Alt 必填，Logo 为品牌标识说明。没有外部热链或过期签名链接。

询盘在线接收属于 S6；本版本显示明确禁用的表单与“待开放”提示，不接受或丢弃访客输入。企业公开联系方式仅来自本次审核引用的已确认事实。

## 数据、索引与迁移

三个新模型全部通过 entity/tenant 插件，组织上下文强制隔离：

| 模型 | 字段 | 索引 |
|---|---|---|
| PublishingSettings | siteId、revision、canonicalBaseUrl、accountId、projectName、productionBranch、domain、AES-GCM secret（默认不选出）、httpsStatus、checkedAt | U(organizationId,siteId) |
| SiteVersion | siteId、number、actorId、operationId/requestHash、status queued/building/ready/failed、冻结 snapshot/snapshotHash、私有 artifactKey/artifactHash、bytes、report、errorCode、active | U(O,siteId,number)、U(O,operationId)、U(O,siteId,active) partial active=true |
| SiteDeployment | siteId/versionId、首次 createdBy、当前执行 actorId、operationId/requestHash、kind publish/rollback、settingsRevision、artifactHash、providerId/providerUrl、attemptedAt、status queued/uploading/verifying/live/failed/unknown、url/errorCode、active | U(O,operationId)、U(O,siteId,active) partial active=true |

Site 增加 versionCounter、currentDeploymentId；套餐增加 publishes（月度 trial/starter/growth：10/50/250，builds 仍为20/100/500）。UsageRecord 使用现有原子预留和一次性结算。构建受理后执行失败计一次构建，提交前拒绝释放预留；成功远端上线才结算发布次数；远端结果不明确时保留预留，不能猜测失败后重复发布。zip 下载不计远端发布，产物本身计存储。已释放但无业务记录的幂等键关闭，后续请求须换新键，避免重用已释放额度。

启动 model.init 自动建立新索引，登记 s5-build-publish-v1。旧数据库、集合、文件、会话均保留；不回填或重建旧页面/图片。无新增环境变量。builder 资源及嵌套生产依赖一并进入 Docker 镜像，普通 node 用户运行。

## 构建、体检与审核

1. 编辑或管理员 GET preflight：地图已确认、无活动 Agent、全部页面存在且当前批准、事实/图片门槛、唯一 title、非空 description/Alt、正文/FAQ/表格合计至少60个单词、正式 HTTPS 根网址。
2. 自动修复只将既有正文前160字符作为缺失描述、将既有图片标题作为缺失 Alt；不补造事实、不处理重复标题/失效图片。修复走 S4 保存，撤回批准，必须重审。
3. 带 Idempotency-Key 排队。事务锁 Site、复核页面/事实、固定配置与输入，仅保存审核引用的 confirmed 事实，不导出未引用的企业资料。
4. Worker 执行前后检查源页 hash、站点 revision/地图、当前权限、事实 revision/状态，防止排队期间源变更。最终落库在租约围栏事务内。
5. 输出链接检查（导航、CSS、图片、锚点）、title/description/H1/Alt 检查；HTML 标准校验在自动测试/质量任务中覆盖三个模板。构建失败不提供半成品。
6. 每文件 SHA-256 清单 globalsite-manifest.json；zip 固定时间戳；整体 artifactHash。不可变 zip 经 storage.service 写入本组织目录；API 无路径参数，下载时校验整体散列。
7. 404.html 防止 Pages 将未知路径当 SPA 首页。只有计划页面进入 sitemap/llms。

发布活动期间锁住站点、地图、页面、审核、相关事实与其产品来源修改；创建发布事务也写 Site/Fact 文档锁，使并发编辑冲突重试后看到活动发布。活动 Agent 阻止发布，新 Agent 不能在发布锁内提交。发布后再次改事实，旧版本预览/导出/再次发布立即失效；已经分发的静态站不会被数据库更改自动撤回，运营人员需发布修订或在 Cloudflare 下线。

## SEO / GEO

每页唯一 title/description、英文 lang、viewport、canonical。生成 sitemap.xml、robots.txt（明确放行 GPTBot、OAI-SearchBot、PerplexityBot、Google-Extended）、llms.txt。这里只生成抓取文件，不承诺机器人一定采纳。

Organization 的企业字段仅来自审核引用的当前已确认企业事实；未确认字段省略。Product 用已审核产品页内容，FAQPage 与可见 FAQ 一致，BreadcrumbList 与站点页面一致；不虚构价格/库存/评分/认证。静态内容无需浏览器 JS。

## 登录预览与 zip

GET /site-versions/:id/preview/* 在现有 Cookie 会话后按组织读取，不生成公开可转发秘密 URL。所有预览响应 private,no-store + X-Robots-Tag noindex,nofollow；HTML 额外 meta noindex。根资源/导航改写至本版本受保护的预览目录，canonical 保持正式网址；CSP 禁脚本与表单提交，仅允许同源资源与同源 frame。正式 zip 不混入预览限制（404 页面单独 noindex）。

zip 可在未配置 Cloudflare 时下载，所有数据检查仍生效。预览可访问历史批准版本；普通新发布必须匹配当前批准稿，回滚可使用历史批准快照，但仍须满足当前事实有效性和域名配置。

## Cloudflare Pages

客户在 Pages 新建 Direct Upload 项目及限定账户的 Pages Write API Token。组织管理员保存账户 ID、项目、生产分支、正式网址与可选域名；Token 使用本站独立主密钥 AES-GCM 加密，AAD 绑定组织和站点。响应仅 configured，不返回明文/密文；仅动作/目标进入审计。前端不持久化 Token，成功后清空输入。

流程：验证项目为 Direct Upload 且生产分支匹配 → upload-token → check-missing → 有界分批 assets/upload → upsert-hashes → multipart manifest 创建 deployment。资产散列算法与官方 Wrangler 一致（base64内容+扩展名的 BLAKE3 前32位）；本地产物完整性另用 SHA-256。请求仅到固定 Cloudflare API，不接受自定义服务端 URL。

依据：[部署 API](https://developers.cloudflare.com/api/resources/pages/subresources/projects/subresources/deployments/methods/create/)、[官方上传实现](https://github.com/cloudflare/workers-sdk/blob/main/packages/wrangler/src/pages/upload.ts)、[官方散列实现](https://github.com/cloudflare/workers-sdk/blob/main/packages/deploy-helpers/src/deploy/helpers/hash.ts)。

远端 POST 前持久化 attemptedAt；不明确响应时只按唯一 commit_message 标记查询原记录，不重发 POST。providerId 先保存后轮询。必须 latest_stage success、project canonical_deployment 指向当前 ID，且 HTTPS 上 manifest 与首页散列匹配，才设置 live/currentDeploymentId。自定义域名也校验同一 manifest/首页，防止指向其他站点。验证请求复用固定公网 IPv4/DNS/重定向/证书检查，不放宽 SSRF。

失败：明确拒绝/远端失败可终止并释放发布预留；不明确保留 unknown 活动锁，最多8次自动核对。管理员可“核对远端结果”重新查询，承接执行权限，不重发发布。发布进行中仅允许同账户/项目/分支/域名/正式网址下替换 Token，同时更新绑定配置 revision，用于恢复过期凭证；不能清空 Token 或切目标。人工外部频繁部署导致标记落出最近100项时须在 Cloudflare 核实，不能猜测释放锁。

回滚不是重跑 Agent/重建：选择曾 live 的版本，重新上传该版本原始 zip 文件和 manifest，生成一条 kind=rollback 的新部署，同样核验生产指针、HTTPS 与散列。目标版本事实已撤回、站点归档、URL改变时拒绝。保留旧发布历史。

API 与远端不能处于同一数据库事务；外部管理员在核验后另行发布、修改域名/缓存，会改变线上结果。本站记录反映最后一次成功核验，不宣称持续监控；后续可加周期一致性检查。

## 域名与可用性

正式网址只允许公开域名 HTTPS 根地址，无用户信息、端口、查询或路径。没有 Cloudflare 也可填写将来部署网址用于 zip canonical。

自定义域名在 Cloudflare 控制台绑定，按其 DNS 指引配置；本站不自动修改 DNS。通过 Pages domain active + 安全 HTTPS GET 检测后才允许该自定义域名新发布；检查24小时内有效。首次可先用项目.pages.dev 发布，再绑定域名、检测和重建。证书尚未生效显示 pending/failed，不禁用管理台/zip。

版本和部署列表返回最近100条；目前无删除/留存配置，历史 zip 计存储额度。意外进程崩溃可能留下私有临时目录，需运维确认无活跃构建后清理；不自动删除真实数据卷。

## 权限与交付验证

所有新模型 tenant fail-closed；查询/图片/导出按本组织；editor 可体检/修复/构建/提取配色；admin 才能配置/发布/回滚/核对；viewer 只读。所有写请求沿用精确 Origin 和 CSRF；未授权访问历史预览返回401/404。

测试包括真实 HTTP 契约、跨组织/RBAC、真实 Astro 构建、HTML 校验、幂等/额度/租约、源变化/事实撤回、发布编辑锁、加密/审计、Cloudflare 上传格式和 HTTPS 校验、回滚文件逐字节相同、模糊 POST 不重发与恢复、更换 Token，以及完整 S2–S5 浏览器流程。

见 [S5运行与验收](../operations/S5-运行与验收.md)。真实 Cloudflare 凭证/客户域名未配置，远端流程使用隔离模拟，不能将其称为真实云端已部署。
