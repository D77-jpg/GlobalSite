# S32 多风格旗舰独立站渲染引擎

本阶段只修改 GlobalSite（`server/builder/composition.css`、本地 SIL OFL 字体资产与文档），不修改 GlobalCRM 或其契约，不破坏现有历史版本与发布门禁。

## 1. 目标与升级范围

为解决此前独立站生成结果落回系统字体（Arial / Georgia）与旧版白底文档样式的问题，本阶段全面升级多轴组合渲染引擎（`composed-site`），使不同外贸行业按业务定位自动匹配差异化的国际品牌官网水准：

1. **本地离线旗舰字体包（SIL OFL 1.1，零外部 CDN 依赖）**
   - 打包 11 个 woff2 字体文件至 `server/builder/fonts/` 与 `web/public/assets/fonts/`，并在 `server/builder/fonts/OFL-LICENSES.txt` 记录许可归属：
     - `Cormorant Garamond`（400 / 600 / 400 Italic）— 奢华与杂志衬线标题（`type-luxury` / `type-editorial`）
     - `Plus Jakarta Sans`（400 / 500 / 600 / 700）— 现代人文正文与标题（`type-sans` 及全局正文）
     - `Space Grotesk`（500 / 700）— 几何科技与德国工业标题（`type-geometric` / `type-technical`）
     - `JetBrains Mono`（400 / 500）— 参数表、型号与技术索引等宽字体
   - 同步补齐 `web/public/assets/fonts/varela-round.ttf`，消除预览资源缺失告警。

2. **9 套高辨识度行业配色体系（均满足 WCAG AA >= 4.5:1 对比度）**
   - `obsidian`：真暗黑建筑奢华（`#0b0a09` 曜石黑底 + `#d4a36a` 暖古铜金强调），适配高端意式咖啡机、建筑照明、声学与精密制造；
   - `ivory` / `clay`：画廊级暖石膏与地中海手作，适配家具、家居与工艺品；
   - `graphite` / `cobalt`：德系精密工程与航空自动化；
   - `ocean` / `forest`：清洁能源/医疗科技与可持续户外材料；
   - `violet` / `brand`：前沿创意与动态客户品牌色派生态。

3. **4 种首屏构图与完整组件重制**
   - `panorama`：全幅电影级 Hero + 双层渐变暗幕 + 左对齐高对比文案区（显式 `fit-contain` 时自动切回无裁切画廊陈列）；
   - `split` / `editorial` / `stacked`：分别面向 50/50 工程对比、杂志不对称排布与科技硬件展示；彻底清除旧版 `.style-industrial` 竖线与灰色底条残留；
   - 统一升级粘性毛玻璃导航、产品/分类卡片、筛选输入框、规格对比表、手风琴 FAQ、RFQ 表单、指标条、认证墙、Bento 专题与悬浮询价栏；
   - Cookie 同意条改用紧凑 Grid 布局并避让 `.quote-bar`，不遮挡首屏视觉主体。

## 2. 安全、性能与门禁保持

- 零运行时外链（字体、样式、脚本全部随静态构建包本地打包分发）；
- 保持 `style-src 'self'` 严格 CSP，无内联样式，不执行模型生成的 HTML/CSS/JS；
- 严格尊重 S23 区块级 `fit-contain` / `fit-cover` / `focus-*` 艺术指导，未裁切产品详情图不产生上下黑边；
- 保留全部事实防幻觉门禁、页面审批门禁与移动 Lighthouse Performance / SEO >= 90 质量验收标准。
