# S8–S11 B2B 建站升级

仅 GlobalSite；CRM 只读，无 Integration API 变化。分支 feat/s8-s11-b2b-agent。

## 交付范围

S8：可选 buyerProfile 定义采购受众、供货模式、采购问题、主要行动、最多三个参考站。规划 Agent 的节点可携带逐页目的、买家问题、事实类型和区块计划。资料缺口从当前确认事实计算，不把竞争对手、产品描述或用户定位当作证据。参考站仅安全读取结构，遵守 robots，不执行脚本或导入其经营数据。

S9：十五种白名单区块；产品列表、品类导航、图文、优势、定制、流程、证据、案例、下载、比较和 CTA 各自渲染。所有文本转义，资料/图片限定本组织，内部链接限于站点路由。首页、分类和产品页采用不同布局；不执行模型代码。旧页面可省略新字段，旧版本不重建。

S10：review 任务冻结当前页面修订，在 Worker 构建受限预览并采集手机/平板/电脑截图和 DOM 指标；截图私有、同组织、计入存储。组织明确启用支持图片输入的模型后才发送缩略图；默认文本审查并明确要求人工看图。refine 仅基于未变更的已完成审查修订页面，保留锁/租约/计量，写入新草稿且撤回批准。每轮都由用户触发，最多原有三次已知失败重试，不自动无限烧额度。

S11：跨页面询价清单使用 sessionStorage（仅产品 ID，无身份数据），回填已有询盘表单，不另建公开提交路径；分类筛选渐进增强，静态内容仍完整。下载目录为经过页面审批的公开资料/静态目录，无隐式开放私有资产。B2B 站真实商业发布要求确认公司联系方式和主要采购数据；预览和审核可展示缺口，不能冒充商业上线。

## 架构与数据

扩展 Site.buyerProfile、SiteBlock.items/layout/tone、SitePlanNode.brief、SitePresentation 可选密度/行动目标；继续使用现有 tenant 模型，无新增集合或索引迁移。review 复用 AgentRun、Task、不可变 storage artifact。新增私有 API 以 foundation.openapi.yaml 为准，Cookie/CSRF/Origin/角色/组织规则沿用。

浏览器审查只访问本轮静态文件，拦截所有外部网络/下载/服务 Worker；独立进程环境不含密钥，有限时间/内存/文件大小。浏览器不可用时任务明确失败而核心服务继续可用；安装方法随 Docker 提供。

## 验收

真实 HTTP 契约、越权、资料缺口、所有新增公开字段的事实校验、非法链接与跨组织资产拒绝；旧模板/版本/回滚测试通过。截图任务及按审查修改必须复查修订/租约，未知 AI 用量不可重试。E2E 覆盖采购定位、区块编辑、下载、跨页询价和审查报告。三模板 HTML 与移动性能/SEO>=90，真实 Agent 整站截图另行验收，不以跑分代替采购内容。


## 使用流程与限制

1. 在采购定位定义目标买家、供货模式、主要行动和参考站；在事实库确认真实资料。访谈每轮最多询问十项缺失资料，回答仍需管理员确认。
2. 运行规划，审核每页目的、采购问题和区块计划，确认地图。参考站读取失败只标为不可用，不猜测其内容。
3. 运行内容生成；页面编辑器显示所有区块和事实/链接问题，站内链接只能指向确认地图或可用锚点。品牌展示可调整密度和按钮目标。
4. 运行质量审查。375/768/1440 截图来自真实浏览器；是否做 AI 看图取决于组织配置。当前文本模型的审查不是视觉评分，必须人工检查截图。无 AI 时仍可做浏览器检查。
5. 按报告修订生成新草稿；重新审查后，由管理员确认报告并逐页批准。质量确认不会替代事实审核。缺采购资料可私有预览，正式发布继续阻止。

目录下载提供静态 HTML 内容，可打印保存；仅显式选择的 PDF 才随产物公开，不承诺自动生成专业 PDF 排版。询价清单保存本次浏览的产品 ID，不存联系人。表单未由站点管理员启用时，清单和表单只作预览，不会接收真实询盘。

本阶段不生成或伪造工厂实拍、证书、客户案例、MOQ、交期；素材仍来自组织资料库。不得把补齐模块数、通过 Lighthouse 或模型的自我评价当作商业验收。浏览器截图只反映给定尺寸下的当前内容，阅读质量和采购证据仍需运营复核。

新增 Playwright 1.56.0 供 Worker 截图，Docker 安装对应 Chromium；核心服务缺浏览器仍能启动，截图任务明确报错。可选 PLAYWRIGHT_BROWSERS_PATH 只指向预先安装的浏览器目录。

截图构建允许保留草稿死链供诊断；release 构建继续拒绝死链。审查报告确定性合并当前事实/链接错误，管理员不能确认仍有此类问题的页面。
