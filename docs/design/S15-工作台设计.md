# GlobalSite 工作台 UI 与交互设计

## 路由审计及实施顺序

| 入口 | 原体验与改造目标 |
| --- | --- |
| 登录、注册、验证 / 重发邮件、忘记 / 重置密码、接受邀请 | 统一身份页构图、字段反馈、校验与返回路径，保留两步验证和开发邮件流程 |
| 概览、Agent | 概览原先突出账号设置；使用真实站点进度定位下一步，Agent 工作台按站点查看执行和产出 |
| 站点列表、站点工作区、页面编辑、预览、构建发布 | 给规划树单独的节点编辑位置；将访谈、任务、审批和版本管理串联，保留历史版本 |
| 产品列表、新建 / 编辑、批次导入、资料库、企业事实、旧站读取 | 区分资料浏览与编辑工具；展示真实缩略图和导入错误；确认事实仍需相应权限 |
| 询盘列表、详情、站点询盘设置、CRM 连接 | 收拢高级筛选和设置；清晰展示当前状态、处理动作与同步结果 |
| 组织设置、成员、个人安全、用量、AI 服务商 | 将低频配置从日常运营导航中分组；保留现有管理员和只读权限 |

先建立品牌色、字号、间距、表单、反馈、列表、响应式和键盘规范，再逐模块迁移。侧栏按工作台、建站与内容、组织设置分组。页面切换器只列出当前角色能看到的页面。新 Agent 入口复用站点已记录的任务和执行步骤，重试和取消使用原权限校验。

## 视觉与交互

白色工作面、低对比中性背景、深绿主操作。绿色底纹用于关键工作区，普通表单以字段和操作为主。标题、说明、状态、主操作各占一个层级；实际任务状态用文字配合颜色。桌面优先保留列表空间；窄屏导航可展开，工具区顺序堆叠。弹窗保留焦点、支持 Escape；尊重减少动态效果的系统设置。缺失资料、空结果、请求失败与仍在加载分别处理，不展示推测的百分比、预计耗时或商业数据。

## 验证

按登录、规划、运行、审核、发布和运营流程验证；同时检查深链接、语言切换、管理员及只读权限、键盘与窄屏。数据库和双方 API 均无需迁移。

地球背景由 Natural Earth 1:110m 公共领域陆地轮廓投影生成，本地 WebP 随应用分发。
