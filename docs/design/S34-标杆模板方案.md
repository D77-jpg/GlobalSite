# S34 标杆模板方案（草案）

> 依据：Eversys、La Marzocco USA、Fellow、Sellick Equipment 首页的文字结构+ 浏览器实测截图与计算样式（2026-11-25）。
> 目标：从"AI 往固定区块填 JSON"转为"设计师级行业模板 + AI 选模板/填内容"，先做设备制造（咖啡设备）一套，验证后再扩展。

## 1. 标杆拆解：它们比我们强在哪

| 维度 | 标杆做法 | Verona Brewtech 现状 |
| --- | --- | --- |
| 首屏承诺 | Eversys：一句结果导向承诺（一致性、速度、工艺），不讲"规格询价" | "Espresso equipment for the working coffee bar" + 讲询价流程 |
| 量化价值 | Eversys：第 1 杯到第 1000 杯口味不变；模块 45 分钟内可换修 | 无任何量化运营价值，只罗列材料 |
| 机型阵列 | Eversys "A System for Everyone"：4 个机型，每个一句"适合谁" | 行式卡片，第一张标题还是分类名 |
| 场景分流 | Eversys：高流量咖啡馆 / QSR / 办公室；La Marzocco：商用 / 家用 | 只有抽象的 "service pattern" |
| 配套销售 | La Marzocco：好机器必须配好磨豆机，独立入口 | "Grinder pairing" 埋在考虑事项卡片里 |
| 社会证明 | La Marzocco：带日期和城市的合作咖啡馆故事；Eversys：人物故事、展会 | 无 |
| 文案风格 | 短句、口号式（La Marzocco 全小写短语）、自信 | 长句、说明书式 |
| 产品摄影 | Fellow：极简棚拍 + 价格 + 套装 | 150px 缩略图 + 等宽字体参数 |

结论：差距主要在**信息架构和内容类型**，不只是 CSS。


## 1.5 视觉实测（浏览器计算样式）

| 站点 | 标题字体 | 首页结构 | 视觉要点 |
| --- | --- | --- | --- |
| Eversys | National 2 Compressed 粗体全大写窄体；正文 Martina Plantijn 衬线 | 深色大字首屏 → 场景图 → 一致性/换修 → 4 机型（米色 #FEF7F1 底）→ 故事 | 窄体大写 + 衬线正文强对比；直角黑底大写按钮；暗背景产品摄影 + 蒸汽氛围；按场景（咖啡馆/酒店/烘焙/QSR/便利店）与功能（萃取/奶/清洁/模块化/联网）双分类 |
| La Marzocco | TradeGothic 全小写 48–65px | 首屏轮播 → 家用 → 商用 → 磨豆机 → 学院 → 新闻 | 全小写品牌口吻；每块一个主题 + 一张满幅真人门店照；米色胶囊按钮（圆角 40px） |
| Fellow | 几何无衬线 | 促销条 → 品类胶囊导航 → 满幅台面场景图 | 品类胶囊横向导航是最强入口 |
| Sellick | Archivo 全大写 | "CONQUER ANY TERRAIN" → 系列卡片 → 找经销商 | 工业感；首屏双按钮"浏览产品 / 找经销商"；Google 4.7 评分作信任 |
| Verona（我们） | 衬线句首大写 | 全站深色、所有块同一边框卡片 | 无明暗交替、无真人/门店照、缺少设备品牌力量感 |

可直接落地的视觉规则：
1. 字体对比：设备类用"窄体/工业无衬线大写标题 + 衬线或人文无衬线正文"，不用衬线大标题配说明文。
2. 明暗交替：区块背景在 深色 / 米色暖白 / 满幅图 之间交替，禁止整站单一深色。
3. 一块一主题一大图：主要区块配满幅或半幅高质量图，替代边框卡片 + 小缩略图。
4. 双维度入口：按场景 + 按品类（胶囊导航）。
5. 按钮品牌化：直角大写（工业）或胶囊（生活方式）。
6. 信任元素：评分、经销商网络或合作门店故事，放在首屏下方。

## 2. 新模板「equipment-flagship」页面骨架（首页）

按顺序，每块都有"素材不足时"的降级规则：

1. **Promise Hero**：通栏图 + ≤6 词承诺 + 1 句结果 + 主/次按钮。降级：无图时用大字排版 + 机器轮廓。
2. **Proof Strip**：3–4 个量化运营指标（产能、换修时间、锅炉稳定性、保修）。降级：无事实则整块省略，后台提示补料。
3. **Lineup**（机型阵列）：每机型一张大图卡：名称、一句"适合谁"、2 个关键参数、查看详情。降级：<2 个机型时改为单品聚焦。
4. **Use-case Split**：按场景分流（精品咖啡馆 / 连锁 / 酒店 / 办公室），每个场景推荐机型。
5. **Pairing Band**：机器 + 磨豆机组合推荐，独立视觉带。
6. **Craft / Engineering**：材料、工艺、可维护性特写图 + 短段落（La Marzocco 式）。
7. **Customization / OEM**：色彩、木饰、品牌面板的可视化选项。
8. **Stories / Partners**：客户案例、城市、日期、展会。降级：无案例时省略，不造假。
9. **Inquiry**：行业化标题 + 精简表单（场景、日杯量、型号、数量、市场）。

规则：首页 ≤ 8 块；连续两块不能同一视觉形态（大图 / 数据带 / 卡片 / 分栏 交替）；任何块素材不足直接省略。

## 3. 实施改动

| 层 | 改动 |
| --- | --- |
| 数据结构 | 新增区块类型 `promise-hero`、`proof-strip`、`lineup`、`use-cases`、`pairing`、`craft`、`stories`（zod + OpenAPI） |
| 渲染 | 新增 `templates/equipment-flagship/` 独立 CSS 与 HTML 片段，不复用现有卡片样式 |
| Agent | 设计步骤先选模板（equipment-flagship / 现有通用），再按骨架逐块填充；提示词加入"结果导向承诺、量化价值、适合谁"写法示例 |
| 校验 | 节奏校验（相邻块形态不同）、素材降级、禁用词改为词根级（confirm*、verified、listed with） |
| 访谈 | 补问：日杯量/产能、换修时间、保修、目标场景、合作客户、展会 |
| 验收 | 与 Eversys 首页截图并排人工评分（首屏冲击、信息密度、可信度、转化路径，各 1–5 分） |

## 4. 需要用户提供

- Verona 是否有可公开的产能/稳定性数据、保修政策、合作客户或展会记录（决定 Proof Strip 与 Stories 是否出现）。
- 是否愿意为每个机型补 1 张白底棚拍 + 1 张场景图（可用 AI 生成并标注示意）。
