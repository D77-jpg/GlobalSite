# S19 Agent 任务中心

## 范围

只修改 GlobalSite 前端的 /agent 与站点工作区“Agent 任务”页；共用任务中心组件。沿用现有组织权限、任务 API、Worker、人工审核和发布门禁，无数据库迁移、环境变量、CRM 契约或业务接口变化。

## 信息结构

- 页面先展示紧凑的站点选择与任务中心，移除原来的大幅装饰横幅和重复的大卡片。
- 左侧显示任务名称、更新时间、状态；选择后右侧只展示当前任务。默认优先需要处理的任务，其次进行中任务，最后最近任务；用户选择在轮询时保留。
- 用户首先看到结果、暂停原因和下一步操作。完成的规划、设计、内容和审查分别指向对应工作区；暂停提供 AI 配置、用量或资料核对入口。
- 重试与取消保留原接口和权限，只读成员不显示修改按钮。操作期间防止重复提交，失败提示显示在所操作的任务内。
- 按实际成功步骤数显示进度，不预测剩余时间。已取消任务与成功任务明确区分；部分产出仍提供入口。
- 执行次数、Token、耗时、输入资料数量、浏览器指标和历史执行记录折叠在“执行详情与用量”。切换任务默认收起，避免技术记录抢占结果视线。
- 当前页提供全部、需处理、进行中、已结束筛选；数量明确标注为当前页，使用既有 cursor 分页浏览更早任务。筛选不宣称覆盖全量历史。
- 站点工作区仅在任务页使用历史游标，规划、设计等其他页面继续读取最新任务，避免查看历史影响后续建站。
- 保留继续建站的规划、审核、检查与发布入口。

## 视觉和可访问性

统一白底、细边框、紧凑间距和语义状态色，状态同时以文字和图标表达。窄屏任务列表横向滑动，详情纵向阅读，页面本身不横向溢出。原生按钮、链接和 disclosure 支持键盘与焦点；手机主要操作至少 44px。

## 验证

新增隔离账号浏览器场景，任务记录为虚构夹具，不发起付费 AI：
恢复任务、取消任务、真实步骤进度、完成报告入口、用量默认折叠、筛选、历史游标、站点任务页复用、中英文、1440/768/390/375 布局和浏览器异常检查。

已有真实 HTTP / Worker 测试及站点浏览器场景继续覆盖重试、取消、权限、持久化和审核。视觉截图仅来自隔离账号，不提交截图或测试数据。
