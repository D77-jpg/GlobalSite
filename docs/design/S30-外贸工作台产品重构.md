# S30 外贸独立站工作台产品级重构（UX 与信息架构升级）

## 背景与目标

在 S24–S29 完成 AI 底座、旗舰官网引擎、分屏编辑器、增长发布与 Obsidian AI Studio 视觉皮肤后，工作台前端仍保留了早期按后端实体平铺的 14 项导航、9 项站点平铺标签以及表格式询盘收件箱，对真实外贸从业者认知负担较高。

S30 在 **100% 保持既有后端契约、事实门禁、人工审批与严格 CSP（零内联样式）** 的前提下，按 **Stage A → Stage B → Stage C** 完成面向外贸人的全链路产品级交互与布局重构。

## 核心改动

### Stage A：统一设计系统 + 5 大外贸支柱导航 + 执行指挥台 + 设置中心

- **去“AI 模板感”的建筑级编辑美学**：全面移除紫色霓虹渐变、发光阴影、径向光晕与过载装饰图标；新增 `web/src/ui/design-system.css`（`.gs-*` 语义化组件与布局系统）与 `web/src/ui/primitives.tsx`（`PageHeader`、`Badge`、`KpiCard`、`EmptyState`）。默认采用 **Warm Architectural Alabaster 暖石膏白（`#F7F7F5` 画布 + 纯白平面 + 极细 1px 分隔线 + 纯碳黑主按钮）**，并支持顶栏一键切换 **True Neutral Carbon 纯中性炭黑（`#0A0A0B` 画布 + 极简纯白主按钮）**；严格满足 CSP `style-src 'self'`（零内联样式）。
- **5 大外贸支柱导航（`web/src/workspace-frame.tsx`）**：将原 14 项工程师向侧栏重构为面向外贸业务动线的 5 大核心入口——**指挥台 (`/`)**、**建站工作台 (`/sites`)**、**外贸资料中心 (`/products`)**、**询盘与获客 (`/inquiries`)**、**系统设置 (`/ai` / `/organization`)**，顶部置入醒目的 **「+ 新建外贸站」** 快捷按钮；同时保留 `Ctrl K` 命令面板内的全部 15+ 深度直达路由。
- **外贸独立站执行指挥台（`web/src/overview.tsx`）**：重写工作台首页，集成品牌氛围首屏与站点切换器、4 张 Bento 核心 KPI 卡片（含接入 `GET /api/v1/inquiries/summary` 的有效询盘与跟进处理率）、交互式 **4 步建站上线推进路线**（高亮当前阶段并一键直达）、无站点时的 3 步冷启动引导，以及右侧「页面审核队列」与「近期 Agent 任务」实时卡片。
- **统一系统设置中心（`web/src/settings-hub.tsx`）**：新增 `SettingsShell` 左侧分组子导航，将 `/ai`、`/crm`、`/organization`、`/members`、`/usage`、`/security` 统一收口到「系统设置」工作区，同时保留所有历史路由完全兼容。

### Stage B：一体化沉浸式 Site Studio 与常驻 AI 建站副驾驶

- **常驻 AI 建站副驾驶（`web/src/site-copilot.tsx`）**：新增 `SiteCopilot` 左侧常驻智能副驾驶面板，根据当前站点的真实进度（规划确认 / 设计方案 / 页面草稿 / 审核比例）动态推荐「下一步最佳操作」，支持在当前站点内用大白话直接下达 AI 建站指令（完整保留显式 AI 用量同意勾选与确认结构前置校验），并实时展示最近任务动态。
- **4 阶段引导式建站工作台（`web/src/sites.tsx`）**：将原 9 项平铺站点标签重构为顶部 **4 阶段向导头**（`① 资料与定位` → `② 结构与视觉` → `③ 页面精修` → `④ 质检与上线`）+ 阶段内上下文分段切换器，右侧一键直达「构建与发布」「询盘设置」「预览网站」，大幅降低外贸人建站心智负担。

### Stage C：统一外贸资料中心 + 分屏邮件式询盘工作台

- **统一外贸资料中心（`web/src/knowledge-hub.tsx`）**：新增 `KnowledgeShell` 顶部水平分段切换器，将 **产品库 (`/products`)**、**资料库 (`/assets`)**、**企业事实库 (`/facts`)** 与 **旧官网读取 (`/website-reads`)** 整合为单一「外贸资料中心」入口，非产品列表页右上角提供一键「导入 Excel / 新建产品」快捷操作。
- **分屏式外贸询盘工作台（`web/src/inquiries.tsx`）**：将原长表格收件箱升级为左侧可滚动客户线索卡片列表 + 右侧即时全文阅读与快捷状态切换（`新询盘` / `跟进中` / `已处理` / `垃圾`）的分屏邮件客户端体验，保留完整来源漏斗统计、CSV 导出与独立详情页深链。

## 兼容与安全门禁

- 所有旧路由（`/products`、`/assets`、`/facts`、`/website-reads`、`/organization`、`/members`、`/security`、`/usage`、`/ai`、`/crm`、`/agent`、`/sites/:id`、`/pages/:id`、`/inquiries`）保持 100% 路由兼容，新增 `/knowledge` 与 `/settings` 聚合跳转入口并加入 `safeReturnTo` 白名单。
- 严格保留 AI 显式同意勾选、事实确认门禁、页面审批门禁、租约围栏及零内联样式 CSP 规范；`localStorage` 仅存语言与明暗主题偏好，不存任何凭证或密钥。
- 通过真实 Playwright 浏览器渲染截图完成桌面（1440×900 暗色与亮色）及移动端（390×844）全核心页面视觉验收，消除旧版 `.catalog button` / `.catalog .secondary` / `.inquiries article` 样式穿透冲突。

## S31 视觉策略工作室与三栏沉浸空间升级

对照高端创意设计工作室参考蓝本，将视觉氛围与三栏信息空间进一步拉升：

- **Velvet Obsidian 视觉语言与本地艺术背景**：默认暗黑绒面黑曜石（`#08070D`）+ 紫晶微光玻璃层次，侧栏底部与各工作室顶栏报头集成离线打包的本地建筑曲面与暮色山脊视觉资源（`web/public/assets/studio/hero-arch.jpg`、`sidebar-horizon.jpg`、`storefront-showcase.svg`），零外网运行依赖，同时保留顶栏一键切换浅色模式。
- **双语双行工作室导航（`web/src/workspace-frame.tsx`）**：7 项侧栏入口以中英双语层级呈现（`视觉策略工作室 / Visual Strategy Studio`、`项目看板 / Launch Cockpit`、`产品资产 / Product Library`、`品牌知识与事实库 / Brand Facts & Knowledge`、`询盘与线索 / Inquiries & Leads`、`AI 服务商 / AI Providers`、`团队与协作 / Team & Access`），并修复固定侧栏导致的 244px 双重水平偏移，全屏释放三栏画布宽度。
- **三栏视觉策略与蓝图工作室（`web/src/site-studio-visuals.tsx`、`web/src/site-copilot.tsx`、`web/src/sites.tsx`）**：
  - 顶部建筑曲面报头 `StudioMasthead`（含斜体衬线英文副标题）；
  - 左栏发光球体 `AI 策略顾问` + 3 项可点选建站目标卡片 + 品牌定位快照 + 受控 AI 任务下发器；
  - 中栏 4 项双语视觉切换器、垂直节点时间轴（`网站结构规划`）+ `首页 Hero 方案` 卡片条，并在规划视图升级为可视化站点蓝图组织树（`Home` 根节点连接子页面卡片与区块检视器）；
  - 右栏常驻 `实时网站预览`（支持桌面/平板/手机切换）、`产品资产` 与 `企业事实` 双卡、`询盘洞察` / `构建任务`；
  - 底部常驻 `网站生成与上线流程` 里程碑停靠栏。
- **三栏产品资产库 DAM & 品牌知识事实库（`web/src/catalog.tsx`）**：
  - `/assets` 升级为左侧 `AI 资产策展 Agent` 与资产洞察 + 中间分类视觉网格 + 右侧常驻资产详情预览器；
  - `/facts` 升级为顶部含实时确认率进度条的报头 + 左侧核验筛选面板 + 中间企业事实卡 + 右侧 SVG 环形 `事实可信度评估` 仪表盘。
