# Monolith rendering pack (composition.pack = "monolith")

Use `composition.pack = "monolith"` for architectural materials, building hardware, facades, structural systems, polymers, acoustics and industrial surfaces, paired with `typography = "technical"`, `palette = "graphite"` or `"cobalt"`, and `radius = "sharp"`. Keep the same pack on every page of that direction.

## Home skeleton
Crisp architectural hairline grid with alternating light stone and deep slate bands:
1. Architectural hero (≤7 words, crisp edge-to-edge material/project scene or framed specimen).
2. `metrics` technical performance band (confirmed specs, tolerances or capacity only).
3. `category-grid` or `product-grid` system index (clean structured spec previews).
4. `comparison` technical matrix (model/series comparison table with confirmed values).
5. `split` engineering or installation context.
6. `certifications` or `downloads` (confirmed compliance docs and downloadable PDF spec sheets only).
7. `case-study` architectural project references (confirmed or demo-mode only).
8. Inquiry section (rendered automatically; no duplicate closing CTA).

## Voice and discipline
Precise, architectural, specification-first copy. Emphasize dimensional tolerances, surface durability, compliance documentation and project delivery readiness. Omit any section without supporting facts or visuals.
