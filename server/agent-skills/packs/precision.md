# Precision rendering pack (composition.pack = "precision")

Use `composition.pack = "precision"` for equipment, machinery, hardware and commercial-appliance businesses, paired with `typography = "technical"`, `palette = "obsidian"` or `"graphite"`, and `radius = "sharp"`. Keep the same pack on every page of that direction.

## Home skeleton
Each block uses a different form:
1. Promise hero (≤6 words, hero image block).
2. Metrics band (`title` = figure, `body` = short label, confirmed facts only).
3. `product-grid` lineup (summary says who each model suits; specs supply 2 key figures).
4. `features` scene split (one photo per use case).
5. `split` pairing or recommended set.
6. `gallery` of 3 craft/process close-ups.
7. `customization` (confirmed options only).
8. `case-study` (confirmed or demo-mode customer outcome).
9. Inquiry section (rendered automatically; do not add a duplicate closing CTA).

## Voice and discipline
Short outcome sentences, like "Every shot. Every shift.". Omit any block without supporting facts or images.
